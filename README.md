## 🌐 English Overview

**ArzVin** is a modern, lightweight, and high-performance financial Android application engineered for instant price discovery of:
- Foreign currencies (USD, EUR, AED, GBP, TRY, etc.)
- Gold & bullion (18K, 24K, Melted Gold)
- Central Bank coins (Emami, Bahar Azadi, Half & Quarter Coins)
- Major cryptocurrencies (BTC, ETH, USDT, and more)

### Key Features:
- 🚀 **Zero-lag Live Updates:** Powered by high-speed APIs.
- 📉 **Interactive Charts:** Comprehensive historic trend analysis.
- 🧮 **Multi-Currency Converter:** Instant calculation of financial assets.
- 🌙 **Modern Dark/Light Themes:** Sleek Material Design aesthetics with minimal power footprint.
